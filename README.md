StarBright University

A responsive university department website developed using HTML, CSS, and Bootstrap.

📌 Project Overview

StarBright University is a front-end website designed to present university information in a clean, modern, and responsive layout.

The website includes sections for university information, departments, admissions, gallery, contact, and login.

✨ Features

- Responsive navigation bar
- Home section with university introduction
- About University section
- Departments section
- Admissions information
- Gallery section
- Contact form
- Login form interface
- Responsive design for desktop, tablet, and mobile devices
- Bootstrap-based layout and components

🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any modern web browser.

No additional installation or setup is required.
